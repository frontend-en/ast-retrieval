AST Retrieval

Гибридный поиск по кодовой базе: Qdrant (семантика) + Neo4j (граф вызовов).

Endpoints

  • GET /api/health — статус сервиса и конфигурация
  • POST /api/retrieve — поиск по запросу

Пример запроса

curl -X POST https://your-app.vercel.app/api/retrieve \
  -H "Content-Type: application/json" \
  -d '{"query": "telegram bot authorization"}'

Environment variables (Vercel)

  • OPENAI_API_KEY
  • QDRANT_URL
  • QDRANT_COLLECTION (optional, default: code)
  • NEO4J_URI
  • NEO4J_USER
  • NEO4J_PASSWORD
